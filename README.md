# Gerenciador Financeiro

Um programa desenvolvido em Java para auxiliar no controle de saldo e na organização de diferentes fundos financeiros.

> **Projeto #1 — Desenvolvimento independente**

## 📌 Sobre o projeto

O **Gerenciador Financeiro** permite informar um saldo atual e consultar diferentes categorias de fundos, ajudando a visualizar quanto dinheiro está reservado e quanto permanece disponível.

Este projeto está sendo desenvolvido como parte do meu processo de aprendizado e prática com Java.

## ⚙️ Funcionalidades

Atualmente, o programa possui:

* [x] Informar o saldo atual
* [x] Consultar fundos essenciais
* [x] Exibir o valor guardado em cada fundo
* [x] Exibir o valor disponível após os fundos essenciais
* [x] Consultar fundos alocados
* [ ] Calcular despesas mensais
* [ ] Salvar informações
* [ ] Adicionar novas categorias de fundos

## 💰 Fundos essenciais

Atualmente, o programa trabalha com os seguintes fundos essenciais:

* **Alimentação:** R$ 500,00
* **Higiene pessoal:** R$ 200,00
* **Gás:** R$ 120,00

Os valores poderão ser modificados conforme o desenvolvimento do projeto.
